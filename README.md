# Extract

**Extract and organize valuable information from any webpage with one click.**

Extract is a privacy-first Chrome extension that helps you pull structured data from web pages and save it for later. No accounts, no cloud storage, no data collection—everything stays on your device.

---

## Features

### Link Extraction
- **Internal Links** - All links within the same domain
- - **External Links** - Links to other websites
  - - **Social Media Links** - Automatically detected (Twitter, LinkedIn, YouTube, GitHub, etc.)
    - - **File Links** - Organized by type (PDFs, images, videos, documents, and more)
     
      - ### Contact Information
      - - **Email Addresses** - Extracted from mailto links and page content
        - - **Phone Numbers** - US phone numbers in all common formats
         
          - ### Content Extraction
          - - **Page Text** - Clean text content with reader view
            - - **Markdown Export** - Text converted to markdown format
              - - **Headings Structure** - H1-H6 hierarchy outline
                - - **Tables** - Extracted as structured data
                 
                  - ### Meta & SEO Data
                  - - Page title and description
                    - - Open Graph data
                      - - Twitter Card data
                        - - Keywords and author
                          - - Canonical URL
                           
                            - ### Data Management
                            - - **Local Storage** - Everything saved in your browser
                              - - **Browse by Domain** - Group pages by website
                                - - **Browse by Date** - Chronological view
                                  - - **Search** - Find pages by title, URL, or domain
                                    - - **Copy to Clipboard** - One-click copy for any data group
                                      - - **Export to CSV** - Download page data as spreadsheet
                                        - - **Backup & Restore** - Export/import all data as JSON
                                          - - **Auto-Expire** - Optional automatic cleanup (30/60/90 days)

                                            ## How to Use

                                            1. **Navigate** to any webpage you want to extract data from
                                            2. 2. **Click** the Extract icon in your browser toolbar to open the side panel
                                               3. 3. **Click** "Extract This Page" to analyze the current page
                                                  4. 4. **View** your extracted data organized into groups
                                                     5. 5. **Copy** any group with one click, or export everything to CSV
                                                       
                                                        6. The side panel stays open as you browse, automatically updating to show the current page.

                                                                    ## Permissions

                                                                    | Permission | Purpose |
                                                                    |------------|---------|
                                                                    | `activeTab` | Read current page content when you click Extract |
                                                                    | `tabs` | Detect tab changes so the side panel updates automatically |
                                                                    | `storage` | Save extracted data locally |
                                                                    | `clipboardWrite` | Copy data to clipboard |
                                                                    | `sidePanel` | Display the UI in Chrome's side panel |
                                                                    | `alarms` | Run periodic cleanup of expired data |

                                                                    We request only what's necessary—nothing more.
